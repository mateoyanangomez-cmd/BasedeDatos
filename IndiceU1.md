# 📘 Unidad 1: Fundamentos y Modelado

Breve introducción conceptual para la presentación de la **Unidad 1** de la materia de Base de Datos.

---

### 📐 1. Diagrama Entidad-Relación (E-R)

Es una herramienta de modelado conceptual que permite representar la estructura lógica de un sistema 
mediante **entidades** (objetos o conceptos del mundo real), **atributos** (sus características o propiedades) 
y las **relaciones** que existen entre ellas. Su objetivo es visualizar el diseño de la base de datos de forma 
gráfica antes de llevarlo a código.

---

### 🔗 2. Modelo Relacional

Es un modelo lógico de datos basado en la teoría de conjuntos y la lógica de predicados. 
Organiza la información en **tablas** (relaciones) compuestas por **filas** (tuplas o registros) y **columnas** 
(atributos o campos). Las tablas se conectan entre sí mediante claves primarias y foráneas,garantizando la 
consistencia e integridad de los datos.

---

### ⚡ 3. SQL (Structured Query Language)

Es el lenguaje de programación estándar y declarativo diseñado para interactuar con sistemas de gestión de 
bases de datos relacionales (SGBD). Permite definir estructuras de datos, modificarlas, controlarlas y 
realizar consultas complejas para extraer, actualizar o eliminar información de manera eficiente.
